AI时代，失业和财富爆炸并存——它们属于两个完全不同的群体#

一边是少数人在疯狂赚钱，另一边是更多人在为生计焦虑——这是AI时代的平行世界。

一、同一天发生的两个故事：烈火与繁荣#

2026年6月1日，韩国发生了两件事。

上午10点32分，SK海力士清州4园区气体机房突然起火，氟化氢泄漏，3600人紧急疏散。

几乎就在同一时间，韩国综合股价指数（KOSPI）盘中首破8600点关口，总市值突破7000万亿韩元（约合3.2万亿美元）。海力士股价一度冲高，这家公司刚刚在一周前市值突破1万亿美元，成为亚洲第三家摸到这道线的科技企业——前两家分别是中国台湾省的台积电和韩国的三星电子。

一边是工厂里的惊魂时刻，一边是资本市场的财富盛宴。这两幅画面拼接在一起，就是AI时代最真实的写照。

二、海力士员工的"甜蜜烦恼"：人均85万美元奖金背后#

就在事故发生前两周，韩国媒体炸了：SK海力士员工人均奖金可能高达85万美元。

这个数字源于投行麦格理证券的预测：如果海力士2027年营业利润达到447万亿韩元，按10%分红计算，3.5万名员工人均能拿到12.9亿韩元——约85万美元。

这不是天方夜谭。海力士在HBM（高带宽内存）领域占据全球57%的市场份额，英伟达全系AI加速卡都用它的芯片。2026年Q1营业利润率飙到72%——每卖100块，72块是利润。这已经不是赚钱，这是印钞。

韩国职场现在流行一个新词：“海医齿韩”——海力士、医学院、牙医学院、韩医学院。海力士的职位已经排在医学等传统精英职业之上。

《朝鲜日报》报道了一个细节：今年2月5日海力士发奖金当晚，京畿道利川市园区周边餐厅全部爆满，烤肉店老板说提前做了准备还是忙不过来。园区附近50米内的两个楼盘，一个已售罄，另一个签约率达85%。沿着通勤班车路线，多个区域的房价在飙升，形成了"班车站点板块"。

甚至连婚恋市场都变了。过去韩国人择偶偏爱三星、现代、LG，现在海力士员工成了香饽饽，抢手程度与医生律师平起平坐。有综艺节目调侃：海力士员工出去相亲时，会先假装自己在三星上班，遇到好对象才坦承真实身份。

但另一面呢？

因为奖金与出勤天数挂钩，员工主动回避产假。有已婚夫妇说：“假设有5亿韩元奖金等着，休六个月损失2.5亿，根本休不下去。”

而就在这样的财富盛宴旁边，是工厂里随时可能发生的安全事故。

三、失业和财富是两个群体的故事#

很多人讨论AI时，要么陷入"技术乐观主义"——AI会创造更多工作，人人都会受益；要么陷入"技术悲观主义"——AI会取代人类，大多数人都会失业。

我想说：这两种观点都错了。

AI时代的真相是：失业和财富并不矛盾，它们属于两个完全不同的群体。

一边是掌握AI核心技术、控制关键供应链的人——他们在疯狂积累财富。海力士就是最好的例子：凭借在HBM领域的垄断地位，它的利润率高达72%，员工奖金拿到手软。

另一边是那些工作容易被AI取代、或者在传统行业挣扎的人——他们面临的是收入停滞、甚至失业的风险。

这两个群体，看似生活在同一个国家、同一个时代，但其实是在两个平行世界里。

海力士的员工拿着几百万奖金买房买车的时候，韩国其他行业的年轻人可能在为一份稳定工作发愁；海力士市值突破万亿美元的时候，韩国社会的贫富差距正在拉大到前所未有的程度。

这就是AI时代的残酷真相：技术进步带来的财富增长，并不是均匀分布的。它像一个聚光灯，只照亮少数人，而把更多人留在黑暗里。

四、韩国政府和社会的反应：在焦虑中寻找平衡#

面对这样的局面，韩国政府和社会是什么反应？

1. 国家层面：全力押注AI产业链，转变成AI上流国家#

韩国政府2025年就设立了最多50万亿韩元（约合346.7亿美元）的"尖端战略产业基金"，助力半导体、AI等先进产业发展。还推出新签证政策吸引高端人才。

为什么这么着急？因为韩国太清楚了：在AI时代，抓住核心产业链就是抓住财富。海力士就是韩国的"国家宝藏"，它不仅创造税收，更是韩国在全球科技竞争中的筹码。

2. 民众的财富起飞梦：从"学历崇拜"到"产线崇拜"#

当海力士员工人均奖金可能高达85万美元、三星半导体员工奖金约38万美元的消息传开，韩国社会彻底沸腾了。

韩国职场现在流行"kingsanjik"（国王工人）这个词，指的就是在海力士、三星半导体拿着巨额奖金的一线技术工人。印着海力士logo的T恤在网上拍卖，这些员工在相亲市场广受欢迎。

首尔大学和《朝鲜日报》的联合调查显示：79%的韩国人担心AI会扩大社会差距，55%的人认为AI技术发展会加深社会经济不平等。

而现实正在印证这种焦虑。韩国央行数据显示：2022年11月以来的三年间，韩国青年在信息服务、出版和专业服务等白领岗位的就业人数分别下降了23.8%、20.4%和8.8%。2025年韩国1200名CPA（注册会计师）合格者中，仅338人顺利进入实习注册环节。

年轻人的职业选择正在发生剧变。2026年选择放弃四年制大学转而就读职业院校的学生人数达到创纪录的2500人，同比增长23%。一项针对韩国Z世代求职者的调查显示：60%的受访者宁愿选择一份年薪7000万韩元、需要轮班的生产类工作，也不愿选择年薪3000万韩元、无需加班的办公室工作。

韩国社会正在出现一种"同代人命运分叉"现象：一边是半导体核心岗位进入超级红利周期，另一边是写字楼里的初级会计、法律助理、程序员岗位正在被AI工具压缩。过去年轻人相信"上名校，考资质，当白领"，现在他们发现：穿无尘服进半导体产线，可能比穿西装进CBD更接近中产生活。

3. 企业财富是否应该分配给国家和个人？一场正在发酵的大辩论#

2026年5月11日，韩国总统政策室长金容范在Facebook发布长文，提出一个爆炸性问题：AI时代的超额利润，凭什么不分给全体国民？

这个提议瞬间点燃了韩国社会。5月12日，KOSPI指数从7999点直接跌穿7400点，日内最大跌幅超过7%。市场恐慌"超额利润税"即将到来。

金容范随后澄清：资金来源是AI繁荣带来的"超额税收"，不是直接向企业征税的新机制。他参考挪威发现石油后建立的国家主权财富基金，提议把AI繁荣转化为长期社会资产，用于青年创业基金、农村基本收入、艺术支持或AI时代的转型教育项目。

但这场辩论已经拉开。

支持方认为：

  • 半导体产业的繁荣不仅是企业努力的结果，更是国家战略支持、社会资源集中的产物
  • 2025年韩国法人税收入84.6万亿韩元，同比增加22.1万亿韩元，增长35.3%，主要来自半导体产业
  • 半导体产业每创造10亿韩元产值仅能带动2.1个就业岗位，仅为制造业平均水平的三分之一，财富效应极度集中
  • 需要通过再分配让全民共享AI红利

反对方认为：

  • 把企业利润定义为"超额利润"带有价值判断，暗示这些收益是不公平获得的
  • 三星、海力士经过几十年研发投入和全球竞争才取得今天的成就，不应被视为"等待回收的对象"
  • 全球各国都在补贴半导体企业争夺投资，韩国却讨论"回收超额利润"，这会向市场发出错误信号
  • 应该建立公共AI基础设施、提供全国AI技能培训，而不是直接分钱

这场辩论的本质是：AI时代的财富，究竟是企业私有财产，还是某种意义上的"公共利益"？

4. 国家的财富分配机制：金融措施与税收改革#

为了让普通民众分享AI红利，韩国政府推出了一系列金融措施和税收改革：

措施一：股市相关政策

  • 个股杠杆ETF放开：2026年4月，韩国紧急修订规则，放开个股杠杆ETF限制，单只个股持仓上限提高到100%，专门为三星、海力士两家龙头放行。5月27日，韩国首批三星电子、SK海力士两倍杠杆ETF正式上市，首日狂揽28亿美元资金。
  • 未成年人股票账户赠与税优惠：爸妈给19岁以下孩子股票账户里转2000万韩元（约1.4万美元），10年内不用交赠与税。一个家庭通过分批转账，能给孩子1.4亿韩元还不用交税。
  • 全民炒股热潮：到2026年5月，韩国活跃的股票账户有1.05亿个，但韩国总人口才5160万，平均每人有两个账户。18岁以下孩子新开的股票账户同比增加1000%。

措施二：税收改革

  • 企业所得税上调：2026年1月1日起，年应税收入3000亿韩元以上的大企业所得税税率从24%回升到25%。
  • 高分红企业税收优惠：分红率40%以上的企业，股东的现金分红可以选择单独征税，最高税率从综合征税的45%降到30%。
  • 国内最低补充税：确保在韩国运营的大型跨国企业集团在韩国的有效税率不低于15%。
  • 半导体投资税收优惠：大企业半导体设备投资抵免率从15%提升到20%，中小企业从25%提升到30%；研发费用税收减免率最高可达50%。

措施三：国民成长基金

  • 韩国政府计划推出150兆韩元规模的"国民成长基金"，投资于AI、半导体、生物、二次电池等尖端产业。
  • 投资该基金3年以上，最高可获得40%的所得税抵扣，投资限额2亿韩元。
  • 基金产生的分红收入，5年内按9%单独征税。

这些措施的利弊：

利：

  • 让普通民众有机会通过股市、基金参与AI财富增长
  • 税收优惠鼓励企业分红和再投资
  • 推动资本留在国内，支持本土产业发展

弊：

  • 杠杆ETF风险极高，可能导致散户巨额亏损，被舆论称为"全民赌场"
  • 股市繁荣加剧贫富差距：2026年第一季度，韩国收入最高的20%家庭月均收入是最低20%家庭的6.59倍，创下近6年新高
  • 政策目标与实际效果可能存在偏差：年轻人还是很难进入半导体核心岗位，财富分配机制仍不完善

韩国社会出现了一个新词：“霹雳穷人”——本来日子过得还凑合的普通上班族，突然发现身边的同事或朋友靠股票一波赚了自己十年的工资，自己一对比，瞬间觉得自己像个穷光蛋。这种情绪正在推着更多人疯狂涌入股市。

五、AI呼啸而来，没有旁观者，都是参与者#

海力士的故事，不是别人家的故事。是这个时代的缩影。 每个国家 每个人都会被影响。
